## Unduh

Pilih **satu** berkas di bagian *Assets* di bawah, sesuai perangkatmu:

| Perangkat | Berkas |
|---|---|
| Windows 10/11, laptop Intel/AMD (paling umum) | `FlexStudy_{{version}}_x64-setup.exe` |
| Windows 11 di ARM (Snapdragon X, Copilot+ PC) | `FlexStudy_{{version}}_arm64-setup.exe` |
| Windows, dipasang untuk semua pengguna (butuh admin) | `FlexStudy_{{version}}_x64_en-US.msi` |
| Android 13 sampai 17 | `FlexStudy_{{version}}_arm64.apk` |

Tidak yakin laptopmu ARM atau bukan? Buka *Settings → System → About*. Kalau *System type* bertuliskan "ARM-based processor", pilih ARM. Selain itu pilih x64.

Berkas `.sig`, `latest.json`, dan `android.json` dipakai aplikasi untuk memeriksa pembaruan. Kamu tidak perlu mengunduhnya.

## Cara memasang

**Windows**

1. Unduh installer yang sesuai perangkatmu.
2. Buka berkasnya. Kalau muncul *Windows protected your PC*, pilih **More info → Run anyway**. Peringatan ini muncul karena installer belum memakai sertifikat penerbit berbayar, bukan karena berkasnya berbahaya.
3. FlexStudy terpasang untuk akunmu tanpa hak admin, dan bisa dibuka dari menu Start.

**Android**

1. Unduh berkas `.apk` langsung di HP.
2. Buka berkasnya. Kalau diminta, izinkan browser atau pengelola berkas untuk *memasang aplikasi tak dikenal*.
3. Kalau Play Protect memberi peringatan, pilih **Detail lainnya → Tetap instal**. Peringatan ini muncul untuk aplikasi yang dipasang di luar Play Store.

**Sudah memasang versi sebelumnya?** Pasang saja di atasnya, datamu tetap ada. Mulai versi 0.7.1, FlexStudy memberi tahu sendiri saat ada versi baru dan memasangnya dari dalam aplikasi lewat *Atur → Pembaruan aplikasi*.

## Data dan privasi

Semua data tersimpan di perangkatmu. Akun dan sinkronisasi bersifat opsional, lewat *Atur → Akun & sinkronisasi*. Cadangkan kapan saja lewat *Atur → Data → Ekspor JSON*.
